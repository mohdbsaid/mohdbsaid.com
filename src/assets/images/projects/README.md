# src/assets/images/projects/

Cover and gallery images for `src/content/projects/*.md` entries. Reference them from a project's frontmatter (`cover:`, `gallery:`) with a path relative to that content file, e.g. `../../assets/images/projects/my-project-cover.jpg` — Astro's Content Layer resolves these through `astro:assets` automatically. See `content-admin/README.md` ("How to add a project").
