# src/assets/images/profile/

Put your profile/author photo here (e.g. `mohammed.jpg`). Once a real photo exists, wire it into the About/Home hero via `astro:assets`'s `<Image>` — see `content-admin/README.md` ("How to replace the profile photo"). No placeholder image is checked in on purpose (see docs/DECISIONS.md ADR-010's precedent) — the hero currently renders initials instead.
